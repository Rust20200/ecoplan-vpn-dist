# ecoplan-vpn-dist

Публичное зеркало **подписанных** файлов клиента EcoplanVPN для Windows:

- `latest.json` — последняя версия клиента (подпись ECDSA P-256, sha256 установщика);
- `servers.json` — подписанный список серверов (клиент берёт файл с наибольшим `serial`);
- `bin/bins.json` — подписанный манифест ядер (xray / sing-box / wintun).

Установщики лежат в [Releases](../../releases) (`EcoplanVPN-<версия>.exe`), ядра — в релизе `bins`.

Клиент проверяет подпись встроенным публичным ключом: файл без валидной подписи игнорируется,
скачанный exe сверяется с подписанным sha256. Приватных ключей и паролей здесь нет.
Файлы обновляет `scripts/publish-update.sh` / `scripts/publish-servers.sh`.
